## Quick-mode interaction proposal

- authenticated route picker: `Quick · Niulai`, `Quick · FightGame`,
  `Full Story`, `Evidence Room`;
- persistent controls: `Back`, progress, elapsed/target time, `Evidence`,
  `Next`, `Exit & lock`;
- arrow keys move between screens; `E` opens evidence; `Esc` closes evidence;
- two-minute target gives a subtle visual cue but never changes screens
  automatically;
- presenter notes remain outside the audience-facing manifest unless John
  explicitly approves another presenter-view design.

## Evidence boundary

evidence room. Private screenshots, recordings, repository content and root
